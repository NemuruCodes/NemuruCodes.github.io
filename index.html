Bio

Highlights

2Skate

I did the ragdoll system and was able to apply it to the NPCs. I used UI toolkit for the interactive UI and made the objectives using a modular framework.

The same ragdoll runs on the player and the NPCs, and new objectives plug into the framework instead of being hard-coded.

Play on itch.io

Guiding Light

I helped develop the interact system and made it modular, as well as helped make the levels. I also made a sonar shader the player could use to help navigate the dark.

The sonar shader lets players read dark spaces, and the modular interact system lets levels reuse the same building blocks.

Play on itch.io

Safari Sanctuary

I created the Lion mini-game, and added the cool-down UI for the ability.

The cool-down UI shows players when the lion's ability is ready to use again.
