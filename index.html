Synopsis

2Skate is a game about working in an 80s roller-rink diner as the only employee, the player must complete all objectives before the timer is up to prevent getting fired.

The player must complete all tasks while on skates controlling each leg indepentally.

Project Brief

Cape Town based studio Free Lives sponsored a physics jam for all interested South African devs who are keen to explore the basics of physics based game design.

The Theme was "Surfing".

The Jam took place over a 9 day period but we continued to improve and ploish the game after this period.

My Role & Contribution
  • Built the ragdoll system and applied it to the NPCs as well as the player
  • Used UI Toolkit to create the interactive UI
  • Made the objectives using a modular framework

The same ragdoll runs on the player and the NPCs, and new objectives plug into the framework instead of being hard-coded.

Synopsis

This Tower Defense game is set in magical world where the player must place & upgrade towers strategically to defend the center tower fromt the Goblins.

Project Brief

This was our Final Game Development Project where we were required to implment a multitude of procedural features, we decide to include:

Procedural Particle Damaging effects, Procedural Map Generation, Procedural Path Generation & Procedural Obstacle Generation.

We where also required to make Shaders for thsi project, we made:

A water shader that deforms a plane, An electricity-like damaging effect that works for the Beam tower beam and Magic Orb shader for the towers.

My Role & Contribution
  • Built procedurally generated terrain with multiple paths leading to the object the player defends
  • Designed ScriptableObject-based towers so new tower types are easy to add
  • Set up enemy pathing with NavMesh, plus a wave system driven by ScriptableObjects
  • Made a procedural electricity shader and VFX for the beam tower

New towers, enemies and waves are created as data assets, so the game can grow without rewriting core code.
